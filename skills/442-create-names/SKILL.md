# Name it

You are naming a product, not describing it. One test governs every step:
a **Comfortable Name** says the category out loud and gets ignored, and
the **Right Name** reads like it was always the name. Comfortable is the
default output, so treat it as the failure and hunt past it.

Run the four phases in order, then verify. Strategy before generation
(pick any word and you get filler), sound before the shortlist (it is
cheaper to fix a name early), and the world before commitment.

## 1. Blueprint

Answer three questions in writing before inventing a single name.

**Audit the landscape.** Collect 12 to 15 names already in the space.
Write the shape they share in one line, such as "all [verb] + [noun]" or
"all lowercase single words". That shape is your **ban list**: a name in
the same shape is the Comfortable Name with a new coat. Note what the
incumbents leave open, because that is the space a Right Name can own.

**Climb to the top rung.** Ladder the offer until it stops being a
feature: feature, then what it does, then what the user gets, then what
that makes possible, then how it feels. Write the top rung as one
sentence. A name aimed at a feature competes with every other feature; a
name aimed at the top rung competes with nobody.

**Interrogate the goals.** Answer four questions, one line each: who wins
with this name (the audience), what winning looks like six months in,
why the name matters now, and what it must say plus what it must never
accidentally say (a rude word, a rival, a slur in a language you ship
to). Write these before you have favourites, because they are the
criteria the shortlist is later judged against.

**Done when:** a ban list, a top-rung sentence, and four goal lines exist
in writing, and no name has been generated yet.

## 2. Treasure hunt

Generate in volume and in buckets, judging nothing yet. Read every bucket
through the top rung, not the feature. Target 40 or more raw candidates
and write them all down, the bad ones included, because the bad ones seed
better ones.

- **Classical roots.** Mine Greek and Latin morphemes for the top rung:
  lux (light), kinesis (movement), sonus (sound), via (path), nova (new).
  Pair a root with one short plain word.
- **Elemental and scientific.** Walk the periodic table, minerals,
  constellations, and biology for words with texture: Cobalt, Basalt,
  Quill, Halide, Solstice.
- **Concept buckets.** Pick one abstract domain and empty it completely:
  motion, light, thresholds, tools, weather, cartography, weaving. Ten
  names from one bucket beats two names from ten.
- **Forced synchronicity.** Name an unrelated field (sailing, jazz,
  wingsuit, beekeeping) and force its vocabulary to answer the top rung
  until one term fits. The obvious answer lives in your category, not in
  that field, so this is the fastest way to break obvious thinking.

**Done when:** 40 or more candidates are written down, each tagged with
the bucket it came from.

## 3. Architect the sound

Say every candidate aloud. A name is heard before it is read, so sound
carries a meaning the logo cannot.

- **Processing fluency.** Aim for two or three syllables, one obvious
  pronunciation, one obvious spelling. If you must spell it to a friend,
  or a stranger reads it back wrong, it is already dead.
- **Sound symbolism.** Front-load consonants that match the intended
  feel: plosives (b, d, g, k, p, t) and hard c for decisive, sharp,
  energetic; sibilants (s, z, sh) for fast and sleek; liquids and nasals
  (l, m, n, r) for soft, warm, flowing. The first sound does its work in
  the first 300 milliseconds, so put the strongest one there.
- **Cut the friction.** Keep q, x, and silent letters away from a name
  that ships internationally, and keep numerals and hyphens out of the
  middle.

**Done when:** every remaining candidate has one obvious reading, and any
candidate whose sound argues against the top rung is struck out.

## 4. Believability test

Mock the finalists into the real world, because a name is judged in
context and never alone. For each one, write:

- a headline that would run in a news story about the product;
- a billboard: the name plus six words, nothing else;
- an app store line: name, one-line description, icon label;
- one spoken sentence from a customer using it naturally, such as "I put
  it in ___".

Keep the names that read like a real company in all four. A name that
becomes a pun or a joke in a headline, or that needs its tagline to make
sense, is a Comfortable Name wearing confidence. Then cut to exactly
three, because a shortlist of fifteen is a pile and three forces a
decision. Give each of the three one line of reasoning: the bucket it
came from, the top rung it hits, the ban-list shape it avoids.

**Done when:** exactly three names remain, each proven in all four
contexts and each carrying its one-line reason.

## 5. Verify before committing

The best name in the world is worthless if it is taken, so check now
rather than after you are attached.

For each finalist, in this order: search the exact name (an existing
company, product, or notable person); check the domain plus the relevant
suffix; search the USPTO trademark database in the software or closest
class; check the app stores and GitHub for a collision. Record a verdict
of live, taken, or close-but-usable, with the evidence and where you
found it. A name with a live company in the same class is out, so reorder
the shortlist instead of lowering the bar.

**Done when:** every finalist carries a live or taken verdict with its
source, and the final two are drawn from the live ones.

## What's next

Register the domain for your top live name today, then read the final two
aloud to three people outside the project and keep the one they can say
back and remember tomorrow.
