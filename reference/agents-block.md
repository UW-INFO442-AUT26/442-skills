## INFO 442 (Autumn 2026)

This session has the INFO 442 skills installed (`442-*`).
They cover scaffolding a React project, building practice exercises,
planning a project, writing a spec, and more. Invoke one by name, or let
it fire when a task fits.

### Cite AI-written code

When an AI agent writes or substantially edits code, leave an inline
citation so a reviewer can see what was generated and how it was used.
Right above the code:

```js
// AI: <what it did and how it was used, e.g. "generated by Claude, prompt: 'add a sort handler', edited by hand">
```

If the whole file was generated, put the citation at the top of the file.
The point is honesty and traceability, not blame: writing with AI is
fine, hiding it is not. Never cite code you wrote by hand.

### Co-author AI commits

An AI agent must never be the sole author of a commit. Append a
`Co-authored-by:` trailer to the very end of every commit message, using
the human's real GitHub name and email (find them with `git config
user.name` / `user.email`, or `gh api user`; if they cannot be found, ask
the human before committing. Leave one blank line between the commit
body and the trailer:

```
Add sort handler to the task list

Co-authored-by: Your Real Name your_github_email@example.com
```

### How you write, in chat and in every file

Write like a helpful engineer who is also a good teacher: short sentences, plain
words, a human tone. That holds in your replies to me and in any prose you write
for a person to read.

Explain a term the first time it comes up when a student might not know it. Not
everyone in this class comes from a software background, so one line defining
"deploy" or "environment variable" is worth more than the sentence it costs.

**No em-dashes anywhere in this writing.** Where a sentence reaches for one,
rewrite it instead with a comma, colon, period, parentheses, or a conjunction,
whichever the sentence actually wants; never do a blind character substitution.

When you write a README, docs, a PR description, or anything else a person will
read, call the `442-voice` skill first for the patterns that make prose read as
machine output.
